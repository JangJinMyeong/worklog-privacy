WorkLogHub

WorkLogHub는 Windows PC에서 실행되는 개인용 업무 도구입니다. 일정 탭에서 사용자의 Google 캘린더 일정을 읽어 한 화면에 보여 줍니다.

개인정보처리방침

시행일: 2026-10-28

1. 접근하는 Google 사용자 데이터

사용자가 동의한 경우에 한해 다음 범위를 읽기 전용으로 사용합니다.

  • 캘린더 목록 조회 (calendar.calendarlist.readonly)
  • 캘린더 일정 조회 (calendar.events.readonly)

2. 데이터의 사용과 저장

조회한 일정은 일정 표시 목적으로만 사용하며, 사용자의 PC 안(로컬 데이터베이스)에만 저장됩니다. 인증 토큰과 클라이언트 보안 비밀번호는 Windows DPAPI로 암호화되어 해당 PC에만 저장됩니다.

3. 수집·공유·판매

개발자나 제3자의 서버로 데이터를 전송·수집하지 않으며, 광고 등 다른 목적으로 사용하거나 제3자에게 제공·판매하지 않습니다. Google API 서비스 사용자 데이터 정책(제한된 사용 요건 포함)을 준수합니다.

4. 삭제와 연결 해제

앱의 "연결 해제"를 누르면 저장된 토큰과 캐시된 일정이 삭제되고 Google 측 토큰이 폐기됩니다. 또한 Google 계정 권한 페이지에서 언제든 접근 권한을 철회할 수 있습니다.
